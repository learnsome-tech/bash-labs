## Goal

You will be able to read and set the exit status of a command to control script execution.

In the lesson: Sometimes you need a command that does nothing but succeed or fail, usually while you are testing the logic around it. The true command does exactly that: it prints nothing and exits with zero. The false command also prints nothing, but it exits with one. These two are the reason you will see a loop written as while true, and the reason a placeholder branch can be filled with a single colon, which is another name for do nothing and succeed.
