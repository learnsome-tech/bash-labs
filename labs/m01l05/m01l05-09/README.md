## Goal

You will be able to read manuals, use command history, auto complete paths, and define aliases.

In the lesson: A recording cannot press tab for you, but the same machinery can be asked directly. The generate completions command lists the candidates for a file name beginning with p o, and there is exactly one, so at a real prompt those two letters and a tab would have written the whole name. Asking for only directories beginning with n o gives the notes folder. Then we use the name it filled in, and read the first two lines of the file, which is a poem about the shell and a fair summary of this module: the shell does not guess what you meant.
