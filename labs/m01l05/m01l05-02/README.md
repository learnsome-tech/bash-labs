## Goal

You will be able to read manuals, use command history, auto complete paths, and define aliases.

In the lesson: Start by asking what kind of command it is. Change directory answers builtin, so the help command has something to say about it, and the description option gives a one line description rather than the full page. Grep answers file, meaning a program on disk, so that one belongs to man. The last line will list the builtins, cut short here to five: everything in that list is documented by help and by nothing else. It is a surprisingly long list, and knowing a name is on it saves you searching the wrong manual.
