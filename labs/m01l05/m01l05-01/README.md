## Goal

You will be able to read manuals, use command history, auto complete paths, and define aliases.

In the lesson: There is no single place to look things up, and that catches beginners out. A builtin lives inside bash, so bash documents it: the help command is the only thing that knows about change directory. A program on disk has a manual page instead, read with man. And most programs also answer a help option with a short usage summary, which is faster when you only need to remember the name of a flag. Looking for change directory in the manual pages gets you nowhere, and asking the help command about grep gets you nowhere either. The type command from the first lesson tells you which door to knock on.
