## Goal

You will be able to read manuals, use command history, auto complete paths, and define aliases.

In the lesson: Define a short name for a listing with two options attached. Using it with an argument shows the substitution clearly: the alias supplied the command and its options, and the rest of the line is still yours, so the folder name lands on the end. Asking for the list of aliases shows the one we made. The type command will tell you what it really is, which is how you find out why a command on somebody else's machine behaves strangely. Take it away again with unalias, and the name means nothing once more: the shell reports it as a command it cannot find.
