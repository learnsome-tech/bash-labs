## Goal

You will be able to read manuals, use command history, auto complete paths, and define aliases.

In the lesson: Clear the list first so the numbering is easy to follow, then run two commands. Asking for the history shows them numbered in the order you typed them. Now the exclamation mark, which shell people call the bang. A bang followed by letters reruns the most recent line beginning with those letters. Two of them repeat the previous line, which is what people put after the word sudo when a command needed rights they forgot to ask for. A bang followed by a dollar sign is the last word of the previous line. Notice that the shell prints the line it settled on before running it.
