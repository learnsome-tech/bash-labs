## Goal

You will be able to read manuals, use command history, auto complete paths, and define aliases.

In the lesson: A manual page opens in a pager, which shows one screen at a time and waits for you, so it cannot be recorded here. Three things make it usable. Press the slash key to search inside the page, n for the next match, and q to quit. The keyword option searches the short description of every page installed, which finds a command whose name you have forgotten. And a page can live in more than one numbered section, which you ask for by putting the number first.
