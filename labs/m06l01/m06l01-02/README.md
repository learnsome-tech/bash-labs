# m06l01-02 · Defining and calling a function

## Goal

Write reusable shell functions that do not leak variables into the global scope.

In the lesson: To write a function, write the name and parentheses, then open a brace. The body contains the commands to run. Close the brace to finish. To run it, just write its name, with no parentheses. Let us call it at the end of the script.
