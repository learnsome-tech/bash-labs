## Goal

Write reusable shell functions that do not leak variables into the global scope.

In the lesson: A function groups commands under a single name. Once defined, you run it just like an external command. Functions help organise long scripts into logical steps, making your code much easier to read and maintain as your scripts grow in complexity over time.
