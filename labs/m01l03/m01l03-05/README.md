## Goal

You will be able to navigate the file system and understand absolute and relative paths.

In the lesson: Three shortcuts save a great deal of typing. A tilde on its own stands for your home directory, so a tilde followed by a slash and a name is an absolute path to something in your home, from wherever you happen to be. Change directory with no argument at all goes home too, which is the fastest way out of a hole. And change directory with a single dash goes back to the directory you were in a moment ago, and prints the place it moved to, so you can bounce between two folders all afternoon. One subtlety worth keeping: the tilde is expanded by the shell before the command ever sees it, so the command receives a perfectly ordinary path and has no idea a tilde was involved.
