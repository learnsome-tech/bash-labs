## Exercises

Open exercises from the lesson, to try on your own. They have no answer files: work them out, and use the labs above as reference.

### Try it yourself

1. From your home directory, reach any folder two levels down, then return using cd with a dash
2. Write the same file as an absolute path and as a relative path from where you are
3. Run ls, then ls piped into cat, and explain why the layout changed

> **Hint:** For the last one, think about who the list command believes it is talking to.

## Check yourself

- What command tells you your current location, and why is its answer always absolute?
- What is the difference between a path starting with a slash and one that does not?
- What do dot, dot dot and tilde mean in a path?
- Why does ls lay its output out differently when you pipe it into another command?
