## Goal

You will be able to navigate the file system and understand absolute and relative paths.

In the lesson: Watch the three shortcuts in one session. Go somewhere deep, two levels down inside the notes folder. Then change directory with no argument, and we are home, which in this sandbox is the work directory itself. Now change directory with a single dash: back to the archive, and notice the shell printed the destination, which is the one case where this command is not silent. Echoing a tilde shows what it expands to, an ordinary absolute path. And the last line lists a folder in the home directory while we are standing somewhere else entirely, which is the point of an absolute path: it does not care where you are.
