## Goal

You will be able to navigate the file system and understand absolute and relative paths.

In the lesson: Change directory, spelled c d, moves the shell. It prints nothing when it works, which is the usual convention: silence means success. So we step into the project folder and confirm with print working directory. The listing shows a readme and two folders, with a slash drawn after each folder because of the classify option. We go one step at a time into the source folder. Then the interesting one: two dots and a name, up and across in a single move, from the source folder to the tests folder beside it, without ever typing the full path. That is relative navigation, and it is how you spend most of your day.
