## Goal

You will be able to navigate the file system and understand absolute and relative paths.

In the lesson: Four listings. The all option on the archive folder shows three entries, and two of them are the dot and dot dot you have been typing in paths: they are real entries in every directory, pointing at the directory itself and at its parent. The next prints one name to a line. The third lists the project folder and classifies them, so you can see at a glance which two of those three are folders. And the last combines a pattern ending in a slash with the directory option to list only the directories inside the project, which is a tidy answer to a question that otherwise needs find. You may notice no long listing here. It shows owner, size and a timestamp, all of which differ on your machine, so this course avoids it on screen.
