## Goal

Use parameter expansion to trim prefixes and suffixes, replace text, and change the case of strings.

In the lesson: You can remove a pattern from the start or end of a string using parameter expansion. These use glob patterns, like the star wildcard, not regular expressions. Use a hash symbol to trim from the start of the string, or a percent sign to trim from the end.
