## Goal

Use parameter expansion to trim prefixes and suffixes, replace text, and change the case of strings.

In the lesson: You can replace a pattern with a new string. The format is the variable name, a slash, the pattern to find, another slash, and the replacement text. A single slash replaces only the first match. To replace all matches, start with two slashes.
