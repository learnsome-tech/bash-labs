## Goal

Use parameter expansion to trim prefixes and suffixes, replace text, and change the case of strings.

In the lesson: You can modify the capitalization of a string. Use a comma to change text to lower case, and a caret to change it to upper case. Just like replacing text, a single symbol changes only the first letter. Double the symbol to change every letter in the string.
