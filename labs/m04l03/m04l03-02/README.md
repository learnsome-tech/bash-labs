## Goal

Use parameter expansion to trim prefixes and suffixes, replace text, and change the case of strings.

In the lesson: Let us assign a file name. To remove the extension, we use the percent sign and the literal string dot see ess vee. The shell removes it from the end. To remove the prefix, we use the hash symbol and the string report dot. The shell removes it from the start.
