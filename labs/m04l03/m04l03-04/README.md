## Goal

Use parameter expansion to trim prefixes and suffixes, replace text, and change the case of strings.

In the lesson: Here are some words. With one slash, the shell finds the first apple and replaces it with orange, leaving the second one alone. With two slashes at the start of the operator, it replaces every apple it finds with orange.
