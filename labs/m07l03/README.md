## Check yourself

- Why does an empty unquoted variable break a single bracket test?
- What can the dollar and parentheses form do that backticks cannot?
- What happens to a variable set inside a function without local?
- What does putting the work in main buy you?
- At roughly what size should a shell script become another program?
