## Goal

You will be able to create, copy, rename, and delete files and directories.

In the lesson: By default, copy and move write straight over an existing file and tell you nothing. Two options change that. The interactive option asks before each overwrite and waits for a yes or a no, which is why it cannot be shown in a recording. The no clobber option makes the command refuse quietly, and that is the one for a script, where nothing is there to answer a question. Many people alias copy and move so they always ask; the alias is not there in a script.
