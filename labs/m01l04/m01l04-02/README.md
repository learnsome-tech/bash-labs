## Goal

You will be able to create, copy, rename, and delete files and directories.

In the lesson: Make directory with the parents option creates the whole chain in one go: the site folder did not exist either, and it did not have to. Touch then brings an empty file into being inside it. Both are silent. The listing afterwards proves it, with the classify option drawing a slash after the folder so you can tell the two apart at a glance. Notice that we created a directory and a file inside a single command each, by giving a path rather than a bare name.
