# Exercises — Single Quotes, Double Quotes, Backslash

Lesson `m02l02` · [Watch](https://learnsome.tech/courses/bash-course/watch?lesson=m02l02)

## Exercise 1: Quote it three ways

1. Print the sentence it is a trap with an apostrophe in it, using each of the three methods
2. Print a line containing a dollar sign, a star and a question mark with nothing expanded
3. Set a variable to your name and print hello followed by it, keeping the space in it

> **Hint**: When a line needs both a literal dollar and an expanded one, reach for the backslash.
