# m01l02-06 · Proving the modern features are there

**Check:** Read along

## Goal

You will be able to check your current shell and its version, and know how to get bash five.

In the lesson: A quick check that you have the good version. Declare a variable as an associative array, store something under a word as the index, and read it back. Ask for a value in upper case with the pair of carets. Then switch globstar on and let a double star match through every directory below the project folder, which finds all three shell scripts in one pattern without running find. Try those five lines on a Mac that has never been upgraded and the very first one fails, because the capital A option did not exist in version three point two. It is a useful thing to paste into a strange machine before you trust it with anything longer.
