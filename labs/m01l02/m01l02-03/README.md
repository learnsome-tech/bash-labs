## Goal

You will be able to check your current shell and its version, and know how to get bash five.

In the lesson: Three commands are given as the answer to this question online, and they answer three different questions. The dollar zero variable gives the name this shell was started with. The process command asks the system what program is really behind the current process, using the dollar dollar variable, which holds its number. The shell variable, spelled in capitals, is the shell recorded for your account in the user database: the one you get when you log in. That last one is the trap. Type bash inside a z shell session and you are in bash, but the shell variable still says the z shell, because nothing updated it. If you want to know what is reading the line in front of you, do not ask it.
