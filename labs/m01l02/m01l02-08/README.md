## Goal

You will be able to check your current shell and its version, and know how to get bash five.

In the lesson: Every system has a package manager, and it is how you get a current bash. On Mac OS, Homebrew, which is not installed by default and is worth installing anyway. On Debian and Ubuntu, apt, and you update the package lists first so it knows what exists. On Fedora and Red Hat, d n f, which replaced yum and still answers to that name. On Arch, pacman with the capital S option. On Alpine, which is what most slim container images are, a p k, and there bash really is missing until you ask for it. All of them except Homebrew need administrator rights, which is why the line starts with sudo. That is the whole of package management you need today; module eight comes back to it properly.
