## Exercises

Open exercises from the lesson, to try on your own. They have no answer files: work them out, and use the labs above as reference.

### Try it yourself

1. Open a terminal and run: echo hello, then run it again with extra spaces between the words
2. Run type -t for three names you use: echo, ls and if. Note which is a builtin
3. Type a deliberately misspelled command and read the error the shell gives you

> **Hint:** The type command takes any name at all, including one that does not exist.

## Check yourself

- What is the difference between a terminal, a shell and a kernel?
- What are the steps of the loop the shell runs for every line?
- Why must change directory be a builtin rather than a program?
- Name three shells other than bash, and say where you would meet them.
