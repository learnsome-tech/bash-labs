## Goal

Use parameter expansion to provide default values, measure string length, and extract slices of a string.

In the lesson: Let us start with an empty variable. To provide a fallback, we use the colon dash form of parameter expansion. If the variable is unset or empty, it expands to the default, which is local host here. If we give it a value, the expansion uses the value instead of the default.
