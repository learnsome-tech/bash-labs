## Goal

Use parameter expansion to provide default values, measure string length, and extract slices of a string.

In the lesson: To extract a slice of a string, use a colon, an offset, another colon, and a length. Offsets start at zero. If you omit the length, it extracts everything from the offset to the end of the string.
