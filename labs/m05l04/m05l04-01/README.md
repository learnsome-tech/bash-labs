## Goal

Write loops to repeat commands, and use break and continue to control them.

In the lesson: When you need to repeat a task, bash gives you three kinds of loops. A for loop runs your commands once for every item in a list. A while loop keeps running as long as a test is true. An until loop does the opposite, running as long as a test is false. And inside any loop, you can use break to stop entirely, or continue to skip the rest of the current turn.
