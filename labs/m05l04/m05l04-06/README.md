# m05l04-06 · The while loop

## Goal

Write loops to repeat commands, and use break and continue to control them.

In the lesson: A while loop tests a condition before every turn. We can use it to make a counter. First, we set a starting value by assigning count to one. Then we write while, and a double bracket test checking if count is less than or equal to three. Inside the loop, we print the current value. Then we use an arithmetic expansion to add one to the count. Without this step, the loop would run forever. The word done closes it.
