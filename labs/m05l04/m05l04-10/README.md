## Goal

Write loops to repeat commands, and use break and continue to control them.

In the lesson: The until loop works exactly like a while loop, but the logic is reversed. It keeps running as long as its test is false, and stops as soon as the test becomes true. This is perfect for waiting for something to happen, like trying to connect to a database or a network host. You just say until the command succeeds, sleep for one second.
