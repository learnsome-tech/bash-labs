## Exercises

Open exercises from the lesson, to try on your own. They have no answer files: work them out, and use the labs above as reference.

### Exercise: count down to liftoff

1. Write a while loop that counts down from 5 to 1.
2. Print each number.
3. After the loop finishes, print 'Liftoff!'

> **Hint:** Use a double bracket test and double parentheses to subtract one.

## Check yourself

- What loop repeats commands for every item in a list?
- What loop repeats commands as long as a test is true?
- What command stops a loop entirely?
- What command skips the rest of the current loop turn?
- Why does an until loop stop when its test becomes true?
