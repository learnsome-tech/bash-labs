## Exercises

Open exercises from the lesson, to try on your own. They have no answer files: work them out, and use the labs above as reference.

### On your own scripts

1. Run shellcheck on the longest script you have written and read every code once.
2. Open the wiki page for one code before you change the line it names.
3. Silence one finding you meant, on one line, with the reason after a second hash.

## Check yourself

- Does shellcheck run the script it checks, and why does the answer matter?
- What separates a warning from an info finding?
- How do you silence one code on one line, and what else belongs on that line?
- Why would you add the severity option when adopting shellcheck on old code?
