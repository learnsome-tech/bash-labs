## Goal

Perform integer math using double parentheses and the let command, and calculate floating point numbers using the basic calculator.

In the lesson: Bash can perform math, but only with whole numbers, called integers. Put your math inside double parentheses to evaluate it. If you want to capture the result, add a dollar sign in front, just like command substitution. When you use variables inside the double parentheses, you do not need to put a dollar sign in front of their names.
