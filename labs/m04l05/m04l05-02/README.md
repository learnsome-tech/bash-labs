## Goal

Perform integer math using double parentheses and the let command, and calculate floating point numbers using the basic calculator.

In the lesson: We assign a width of five. To multiply it by three and print it, we use dollar double parentheses. Notice we just wrote width, not dollar width. We can also use double parentheses on their own as a command. Here we increment the variable by one. When we print it, it is now six.
