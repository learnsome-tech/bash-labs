## Goal

You will be able to read and write a crontab line, and build the report script this course leaves behind for the ones that follow it.

In the lesson: The finished script reads the machine itself, and that is precisely why it cannot be replayed for you: the kernel version, the free space and the process table differ on every host, and a course that printed one machine's answers as though they were yours would be telling you a small lie. The pattern has not changed. Each section prints a heading and then the output of one command. Send the whole thing to a file from cron and you have something to read with your first coffee, and a record of what the machine looked like yesterday.
