## Goal

You will be able to read and write a crontab line, and build the report script this course leaves behind for the ones that follow it.

In the lesson: The h option means human readable, and it turns a column of raw blocks into megabytes and gigabytes. Reach for it every single time. With d u, the s option asks for one summary line for the whole directory instead of a line for every file beneath it, and the two options are nearly always typed together. The use column is the one to watch. The load averages at the end of uptime are the last minute, the last five minutes and the last quarter of an hour, so comparing them tells you whether things are getting worse or settling down.
